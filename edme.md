# Color Toggle Button

## Overview

A simple HTML page featuring an interactive button that changes color on click.

## How It Works

- The page displays a **blue button** centered on the screen.
- **On click**, the button turns **red**.
- **Clicking again** toggles it back to **blue**.

## File

- `button.html` — Contains the HTML, CSS, and JavaScript for the button.

## Usage

Open `button.html` in any web browser to see the button in action.

## Technical Details

| Feature            | Detail                          |
|--------------------|---------------------------------|
| Default color      | Blue (`#2563eb`)                |
| Clicked color      | Red                             |
| Transition         | Smooth 0.3s ease animation      |
| Toggle behavior    | Clicks alternate blue ↔ red     |
| Dependencies       | None (pure HTML/CSS/JavaScript) |
