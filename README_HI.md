# पायथन और SQL से मूवी वॉच‑लिस्ट ऐप

यह प्रोजेक्ट एक साधारण मूवी वॉच‑लिस्ट ऐप है, जो पायथन और SQL डेटाबेस का उपयोग करके फिल्मों को जोड़ने, देखने और प्रबंधित करने की सुविधा देता है।

## मुख्य विशेषताएँ
- मूवी जोड़ना, सूची देखना और प्रबंधन करना
- सरल और हल्का डेटा स्टोरेज (SQL डेटाबेस)
- स्थानीय रूप से चलाने के लिए आसान सेटअप

## प्रोजेक्ट संरचना
- `app.py` — मुख्य एप्लिकेशन लॉजिक
- `database.py` — डेटाबेस हैंडलिंग/कनेक्शन
- `data.db` — स्थानीय डेटाबेस फाइल

## उपयोग कैसे करें
1. रिपॉजिटरी क्लोन करें
2. पायथन (3.x) इंस्टॉल होना चाहिए
3. टर्मिनल में `app.py` चलाएँ

> नोट: यह README हिंदी में फॉलो‑अप के रूप में दिया गया है।
