# Color Toggle Button

## Overview

A simple HTML page featuring a **blue button** that turns **red** when clicked.

## File

- `button.html` — Contains the button UI and click logic.

## How It Works

1. The page loads with a blue button centered on screen.
2. Clicking the button triggers the `turnRed()` JavaScript function.
3. The button's background color changes from **blue** (`#2563eb`) to **red** (`#dc2626`) with a smooth CSS transition.

## Usage

Open `button.html` in any web browser:

```bash
open button.html
```

Or simply double-click the file in your file explorer.

## Technologies

- **HTML5** — Page structure
- **CSS3** — Styling and transition animation
- **JavaScript** — Click event handler to change the button color
