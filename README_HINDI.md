# रंग बदलने वाला बटन

## अवलोकन

एक सरल HTML पेज जिसमें एक **नीला बटन** है जो क्लिक करने पर **लाल** हो जाता है।

## फ़ाइल

- `button.html` — बटन का UI और क्लिक लॉजिक इसमें है।

## यह कैसे काम करता है

1. पेज लोड होने पर स्क्रीन के बीच में एक नीला बटन दिखाई देता है।
2. बटन पर क्लिक करने से `turnRed()` JavaScript फ़ंक्शन चलता है।
3. बटन का बैकग्राउंड रंग **नीले** (`#2563eb`) से **लाल** (`#dc2626`) में एक स्मूथ CSS ट्रांज़िशन के साथ बदल जाता है।

## उपयोग

`button.html` को किसी भी वेब ब्राउज़र में खोलें:

```bash
open button.html
```

या फिर अपने फ़ाइल एक्सप्लोरर में फ़ाइल पर डबल-क्लिक करें।

## प्रौद्योगिकियाँ

- **HTML5** — पेज की संरचना
- **CSS3** — स्टाइलिंग और ट्रांज़िशन एनिमेशन
- **JavaScript** — बटन का रंग बदलने के लिए क्लिक इवेंट हैंडलर
