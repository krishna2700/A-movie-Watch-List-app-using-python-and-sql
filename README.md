# Lista de Películas para Ver

Esta aplicación permite gestionar una lista de películas para ver usando Python y una base de datos.

## Funcionalidades

- Agregar películas a la lista.
- Consultar las películas guardadas.
- Actualizar la información de una película.
- Eliminar películas de la lista.

## Requisitos

- Python 3.x
- SQLite

## Uso

1. Ejecuta la aplicación.
2. Sigue las instrucciones para administrar tu lista de películas.

## Estructura del proyecto

- `app.py`: Punto de entrada de la aplicación.
- `database.py`: Lógica de acceso a datos.
- `data.db`: Base de datos SQLite.
