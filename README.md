# Application de liste de films à regarder

Une petite application Python qui permet d'enregistrer des films à regarder et de les organiser dans une base de données SQLite.

## Fonctionnalités

- Ajouter des films à la liste
- Consulter la liste des films enregistrés
- Stocker les données dans SQLite

## Prérequis

- Python 3.x

## Démarrage rapide

1. Clonez le dépôt.
2. Lancez l'application :

```bash
python app.py
```

## Structure du projet

- `app.py` : point d'entrée de l'application
- `database.py` : gestion de la base de données
- `data.db` : base de données SQLite
