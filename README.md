# Movie Watch List App

A lightweight Python app for tracking movies you want to watch.

## Features
- Add movies with titles and release years
- Store and retrieve movies from a local SQLite database
- Simple, focused codebase for learning CRUD basics

## Project Structure
- `app.py` - Entry point for running the app
- `database.py` - Database helpers and queries
- `data.db` - Local SQLite database file

## Getting Started
1. Ensure Python 3 is installed.
2. Run the app:

```bash
python app.py
```

## Notes
- This project uses a local SQLite database stored in `data.db`.
