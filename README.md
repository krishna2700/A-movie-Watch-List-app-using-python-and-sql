# प्रोजेक्ट README

## परिचय

यह रिपॉजिटरी दो अलग-अलग प्रोजेक्ट्स को शामिल करती है:

1. **मूवी वॉचलिस्ट ऐप** - Python और SQLite का उपयोग करके बनाया गया एक कमांड-लाइन एप्लिकेशन
2. **इंटरैक्टिव बटन** - एक सरल HTML/JavaScript बटन जो क्लिक करने पर रंग बदलता है

---

## 1. मूवी वॉचलिस्ट ऐप

### विवरण

यह एक मूवी वॉचलिस्ट एप्लिकेशन है जो Python और SQLite डेटाबेस का उपयोग करके बनाया गया है। यह ऐप आपको फिल्में जोड़ने, देखने वाली फिल्मों को ट्रैक करने और उपयोगकर्ताओं को प्रबंधित करने की सुविधा प्रदान करता है।

### सुविधाएँ

- ✅ नई फिल्में जोड़ना
- ✅ आगामी फिल्मों को देखना
- ✅ सभी फिल्मों की सूची देखना
- ✅ देखी गई फिल्मों को चिह्नित करना
- ✅ देखी गई फिल्मों की सूची देखना
- ✅ नए उपयोगकर्ता जोड़ना
- ✅ फिल्मों को खोजना

### आवश्यकताएँ

- Python 3.x
- SQLite3 (Python के साथ डिफ़ॉल्ट रूप से आता है)

### स्थापना

1. रिपॉजिटरी को क्लोन करें या फाइलें डाउनलोड करें
2. सुनिश्चित करें कि Python 3.x स्थापित है
3. कोई अतिरिक्त पैकेज स्थापित करने की आवश्यकता नहीं है (SQLite3 Python के साथ आता है)

### उपयोग

ऐप चलाने के लिए निम्नलिखित कमांड का उपयोग करें:

```bash
python app.py
```

### मेनू विकल्प

जब आप ऐप चलाते हैं, तो आपको निम्नलिखित विकल्प दिखाई देंगे:

1. **नई फिल्म जोड़ें** - डेटाबेस में एक नई फिल्म जोड़ें
2. **आगामी फिल्में देखें** - आने वाली फिल्मों की सूची देखें
3. **सभी फिल्में देखें** - डेटाबेस में सभी फिल्मों की सूची देखें
4. **देखी गई फिल्म जोड़ें** - किसी उपयोगकर्ता द्वारा देखी गई फिल्म को चिह्नित करें
5. **देखी गई फिल्में देखें** - किसी उपयोगकर्ता द्वारा देखी गई सभी फिल्में देखें
6. **ऐप में उपयोगकर्ता जोड़ें** - एक नया उपयोगकर्ता बनाएं
7. **फिल्म खोजें** - फिल्म शीर्षक के आधार पर फिल्में खोजें
8. **बाहर निकलें** - ऐप से बाहर निकलें

### डेटाबेस संरचना

#### movies टेबल
- `id` - प्राथमिक कुंजी (INTEGER)
- `title` - फिल्म का शीर्षक (TEXT)
- `release_timestamp` - रिलीज़ की तारीख (REAL/TIMESTAMP)

#### users टेबल
- `username` - उपयोगकर्ता नाम (TEXT, प्राथमिक कुंजी)

#### watched टेबल
- `user_username` - उपयोगकर्ता नाम (FOREIGN KEY)
- `movie_id` - फिल्म ID (FOREIGN KEY)

### उदाहरण उपयोग

1. ऐप शुरू करें: `python app.py`
2. एक नया उपयोगकर्ता जोड़ें (विकल्प 6)
3. कुछ फिल्में जोड़ें (विकल्प 1)
4. फिल्में देखें (विकल्प 3)
5. एक फिल्म को देखी गई के रूप में चिह्नित करें (विकल्प 4)
6. देखी गई फिल्मों की सूची देखें (विकल्प 5)

### नोट्स

- फिल्म जोड़ते समय, रिलीज़ तारीख `dd-mm-YYYY` प्रारूप में दर्ज करें
- यदि आप रिलीज़ तारीख नहीं दर्ज करते हैं, तो आज की तारीख स्वचालित रूप से उपयोग की जाएगी
- डेटाबेस फाइल (`data.db`) ऐप के पहले रन पर स्वचालित रूप से बनाई जाएगी

## 2. इंटरैक्टिव बटन

### विवरण

यह एक सरल HTML/JavaScript प्रोजेक्ट है जो एक नीले बटन को प्रदर्शित करता है जो क्लिक करने पर लाल रंग में बदल जाता है।

### सुविधाएँ

- ✅ आकर्षक UI डिज़ाइन
- ✅ क्लिक करने पर रंग परिवर्तन
- ✅ स्मूथ ट्रांजिशन एनिमेशन
- ✅ हॉवर इफेक्ट

### उपयोग

1. `button.html` फाइल को वेब ब्राउज़र में खोलें
2. बटन पर क्लिक करें - यह नीले से लाल रंग में बदल जाएगा
3. फिर से क्लिक करें - यह वापस नीले रंग में आ जाएगा

### तकनीकी विवरण

- **HTML5** - मार्कअप के लिए
- **CSS3** - स्टाइलिंग और ट्रांजिशन के लिए
- **JavaScript** - इंटरैक्टिव फंक्शनैलिटी के लिए

### फाइल संरचना

```
button.html - मुख्य HTML फाइल जिसमें बटन और JavaScript कोड है
```
