# A-movie-Watch-List-app-using-python-and-sql

## Color Changing Button Demo

This repository includes a simple interactive button demonstration in `index.html`.

### Features

- **Blue Button**: The button starts with a blue background color
- **Click Interaction**: When clicked, the button changes from blue to red
- **Smooth Transition**: Color change includes a smooth CSS transition effect

### How to Use

1. Open `index.html` in any web browser
2. Click the blue button
3. Watch it turn red

### Technical Implementation

- Pure HTML, CSS, and JavaScript (no frameworks required)
- Uses CSS classes to manage color states
- Event listener attached to handle click events
- Responsive design centered on the page
