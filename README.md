# Aplicación de lista de películas para ver

Esta aplicación permite registrar y gestionar una lista de películas por ver usando Python y una base de datos SQL.

## Funcionalidades
- Agregar películas a la lista
- Consultar la lista de películas guardadas
- Actualizar detalles de una película
- Eliminar películas de la lista

## Requisitos
- Python 3
- Base de datos SQLite (incluida con Python)

## Uso básico
1. Ejecuta la aplicación principal.
2. Sigue las instrucciones en pantalla para añadir, editar o eliminar películas.

## Estructura del proyecto
- `app.py`: punto de entrada de la aplicación.
- `database.py`: lógica de acceso a datos.
- `data.db`: base de datos local.
