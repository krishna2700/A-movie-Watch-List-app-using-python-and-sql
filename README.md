# Reset Button Demo

This project includes a simple reset button demo in `index.html`.

## Button Usage

- Open `index.html` in a browser.
- Click the **Reset** button once.
- The button changes from pink text on white to white text on black.
- Click again to confirm the style stays in its reset state.

## What It Does

The button uses a click handler that updates its background and text
color to demonstrate a basic UI state change after a reset action.
