# Color Button Demo

A simple interactive button that changes color when clicked.

## Features

- Button starts as **blue**
- Clicking the button toggles it to **red**
- Clicking again toggles it back to blue

## Usage

Open `index.html` in any web browser.

## Implementation

The button uses a simple CSS class toggle via JavaScript's `onclick` handler. The `.red` class overrides the background color from blue to red.
