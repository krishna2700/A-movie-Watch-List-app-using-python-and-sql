# Een filmlijst-app met Python en SQL

Dit project is een eenvoudige filmlijst-app waarmee je films kunt toevoegen, bekijken en beheren. De app is gebouwd met Python en gebruikt een SQL-database voor de opslag van gegevens.

## Functies

- Films toevoegen met titel, jaar en beoordeling
- Overzicht van opgeslagen films tonen
- Films bijwerken of verwijderen

## Gebruik

1. Start de applicatie met Python.
2. Volg de instructies in de terminal om je filmlijst te beheren.

## Structuur

- `app.py`: Hoofdprogramma
- `database.py`: Database-logica
- `data.db`: SQLite-databasebestand
