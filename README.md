# Movie Watch List App

A simple movie watch list application built with Python and SQLite.

## Features

- Add movies to your watch list
- View all movies in your list
- Mark movies as watched
- Delete movies from the list

## Requirements

- Python 3.x
- SQLite3

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python app.py
```

## Database

The app uses SQLite to store movie data. The database file is `data.db`.

## Project Structure

- `app.py` - Main application file
- `database.py` - Database operations
- `data.db` - SQLite database file
