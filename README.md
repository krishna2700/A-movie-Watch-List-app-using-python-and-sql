# Liste de films à regarder (Python + SQL)

Cette application permet de gérer une liste de films à regarder, stockée dans une base de données SQL. Elle offre des fonctionnalités simples pour ajouter, consulter et organiser vos films.

## Fonctionnalités

- Ajouter un film à la liste
- Consulter les films enregistrés
- Mettre à jour ou supprimer un film

## Prérequis

- Python 3
- Base de données SQL (locale)

## Lancer l'application

1. Cloner ce dépôt
2. Installer les dépendances (si nécessaire)
3. Exécuter l'application avec Python

## Structure du projet

- `app.py` : point d'entrée de l'application
- `database.py` : gestion des opérations SQL
- `data.db` : base de données locale
