# Movie Watchlist App

A simple command-line movie watchlist application built with Python and SQLite.

## Features

- Add new movies with release dates
- View upcoming movies or all movies
- Track watched movies per user
- Search for movies by partial title
- Manage users

## Requirements

- Python 3.10+

## Getting Started

Run the application from the repository root:

```bash
python app.py
```

Follow the on-screen menu to add movies, track watched titles, and search your
watchlist.

## Project Structure

- `app.py` — CLI entry point and menu flow
- `database.py` — SQLite interactions and queries
