# Film-watchlist-app in Python en SQL

Dit project is een eenvoudige film-watchlist applicatie gebouwd met Python en een SQL-database. Je kunt films toevoegen, bekijken en beheren in een lokale database.

## Functionaliteiten

- Films toevoegen aan je watchlist
- Overzicht van alle films bekijken
- Basisbeheer van filmgegevens

## Vereisten

- Python 3
- SQLite (standaard meegeleverd met Python)

## Gebruik

1. Start de applicatie.
2. Voeg films toe aan je watchlist.
3. Bekijk en beheer je lijst.

## Bestanden

- `app.py` – hoofdapplicatie
- `database.py` – databasefunctionaliteit
- `data.db` – lokale SQLite-database
