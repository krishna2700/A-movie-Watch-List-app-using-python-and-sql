# Movie Watch List App

A simple Python + SQL app for tracking movies you want to watch.

## Features
- Add movies to your watch list
- View saved movies
- Update or remove entries

## Project Files
- `app.py` – application entry point
- `database.py` – database setup and queries
- `data.db` – local SQLite database

## Run
1. Ensure Python 3 is installed.
2. Run the app:
   ```bash
   python app.py
   ```

## Notes
- The app uses a local SQLite database stored in `data.db`.
