# फिल्म वॉचलिस्ट ऐप - Python और SQL का उपयोग करके

यह एक Python-आधारित फिल्म वॉचलिस्ट ऐप है जो उपयोगकर्ताओं को फिल्मों को ट्रैक करने, देखने के लिए आगामी फिल्मों को प्रबंधित करने और देखी गई फिल्मों को रिकॉर्ड करने की अनुमति देता है।

## विशेषताएं

### मुख्य कार्यक्षमता

1. **नई फिल्म जोड़ें**: वॉचलिस्ट में रिलीज़ तारीख के साथ फिल्में जोड़ें
2. **आगामी फिल्में देखें**: आगामी रिलीज़ की सभी फिल्मों को ब्राउज़ करें
3. **सभी फिल्में देखें**: डेटाबेस में सभी फिल्मों की पूरी सूची देखें
4. **देखी गई फिल्म जोड़ें**: फिल्मों को देखे गए के रूप में चिह्नित करें
5. **देखी गई फिल्में देखें**: उपयोगकर्ता द्वारा देखी गई सभी फिल्में प्रदर्शित करें
6. **उपयोगकर्ता जोड़ें**: ऐप में नए उपयोगकर्ता बनाएं
7. **फिल्म खोजें**: शीर्षक के आधार पर फिल्में खोजें
8. **बाहर निकलें**: ऐप से बाहर निकलें

## तकनीकी विवरण

### फाइल संरचना

- **app.py**: मुख्य एप्लिकेशन फाइल जिसमें यूजर इंटरफेस और मेनू लॉजिक है
- **database.py**: डेटाबेस संचालन और SQL क्वेरी हैंडलिंग
- **data.db**: SQLite डेटाबेस फाइल जो सभी डेटा संग्रहीत करती है
- **button.html**: एक इंटरैक्टिव बटन डेमो (अतिरिक्त सुविधा)

### आवश्यकताएं

- Python 3.x
- SQLite3 (Python के साथ शामिल)

### डेटाबेस स्कीमा

ऐप तीन मुख्य तालिकाओं का उपयोग करता है:
- **movies**: फिल्म का शीर्षक और रिलीज़ तारीख संग्रहीत करता है
- **users**: उपयोगकर्ता जानकारी संग्रहीत करता है
- **watched**: उपयोगकर्ताओं और उनकी देखी गई फिल्मों के बीच संबंध ट्रैक करता है

## उपयोग

### ऐप चलाना

```bash
python app.py
```

### मेनू विकल्प

ऐप शुरू होने पर, आपको निम्नलिखित मेनू दिखाई देगा:

```
कृपया निम्नलिखित विकल्पों में से एक चुनें:
1) नई फिल्म जोड़ें
2) आगामी फिल्में देखें
3) सभी फिल्में देखें
4) देखी गई फिल्म जोड़ें
5) देखी गई फिल्में देखें
6) ऐप में उपयोगकर्ता जोड़ें
7) फिल्म खोजें
8) बाहर निकलें
```

### तारीख प्रारूप

फिल्में जोड़ते समय, तारीख इस प्रारूप में दर्ज करें: `dd-mm-YYYY` (उदाहरण: 15-03-2026)

यदि कोई तारीख प्रदान नहीं की जाती है, तो आज की तारीख का उपयोग किया जाएगा।

## अतिरिक्त सुविधा: नीले से लाल बटन

इस रिपॉजिटरी में एक अतिरिक्त HTML फाइल (`button.html`) भी शामिल है जो एक सरल इंटरैक्टिव बटन प्रदर्शित करती है।

### बटन सुविधाएं

- **प्रारंभिक अवस्था**: नीली पृष्ठभूमि के साथ सफेद पाठ
- **क्लिक पर**: लाल पृष्ठभूमि में बदल जाता है
- **स्मूथ एनिमेशन**: रंग परिवर्तन के लिए 0.3s संक्रमण प्रभाव
- **उत्तरदायी लेआउट**: केंद्रित और मोबाइल-अनुकूल
- **होवर प्रभाव**: बेहतर उपयोगकर्ता इंटरैक्शन के लिए

### बटन का उपयोग

किसी भी आधुनिक वेब ब्राउज़र में `button.html` खोलें। बटन को नीले से लाल में बदलते देखने के लिए उस पर क्लिक करें।

### तकनीकी कार्यान्वयन

- शुद्ध HTML, CSS और JavaScript (कोई फ्रेमवर्क आवश्यक नहीं)
- CSS क्लासेस और इनलाइन स्टाइल का उपयोग करके रंग परिवर्तन
- बटन क्लिक इवेंट से जुड़ा इवेंट लिस्टनर
