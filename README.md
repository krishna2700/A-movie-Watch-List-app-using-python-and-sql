# Een film-watchlist-app met Python en SQL

Deze repository bevat een eenvoudige film-watchlist-app gebouwd met Python en SQL. Je kunt films toevoegen, bekijken en beheren via een simpele interface die de database bijwerkt.

## Functies

- Films toevoegen aan je watchlist
- Overzicht van alle films
- Opslaan in een SQL-database

## Vereisten

- Python 3.x
- SQLite (standaard inbegrepen bij Python)

## Gebruik

1. Start de applicatie:
   ```bash
   python app.py
   ```
2. Volg de aanwijzingen in de terminal om je watchlist te beheren.

## Bestanden

- `app.py` – hoofdapplicatie
- `database.py` – database-logica
- `data.db` – SQLite-databasebestand
