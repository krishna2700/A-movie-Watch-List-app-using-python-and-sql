# मूवी वॉचलिस्ट ऐप

यह एक Python-आधारित मूवी वॉचलिस्ट एप्लिकेशन है जो उपयोगकर्ताओं को फिल्मों को ट्रैक करने, उन्हें देखे गए के रूप में चिह्नित करने और आगामी रिलीज़ को प्रबंधित करने की अनुमति देता है।

## विशेषताएं

- **नई फिल्में जोड़ें**: अपनी वॉचलिस्ट में शीर्षक और रिलीज़ तारीख के साथ फिल्में जोड़ें
- **आगामी फिल्में देखें**: आज की तारीख के बाद रिलीज़ होने वाली फिल्मों को फ़िल्टर करें
- **सभी फिल्में देखें**: डेटाबेस में सभी फिल्मों की पूरी सूची देखें
- **देखी गई फिल्में चिह्नित करें**: उपयोगकर्ता किसी फिल्म को देखे गए के रूप में चिह्नित कर सकते हैं
- **देखी गई फिल्में देखें**: किसी विशिष्ट उपयोगकर्ता द्वारा देखी गई सभी फिल्मों को देखें
- **उपयोगकर्ता प्रबंधन**: ऐप में नए उपयोगकर्ता जोड़ें
- **फिल्म खोजें**: शीर्षक के आधार पर फिल्मों को खोजें

## आवश्यकताएं

- Python 3.8 या उच्चतर
- SQLite3 (Python के साथ शामिल)

एप्लिकेशन चलाने के लिए:

```bash
python app.py
```

### मेनू विकल्प

ऐप शुरू होने पर, आपको निम्नलिखित विकल्प दिखाई देंगे:

1. **नई फिल्म जोड़ें** - फिल्म का शीर्षक और रिलीज़ तारीख (dd-mm-YYYY प्रारूप में) दर्ज करें
2. **आगामी फिल्में देखें** - आज के बाद रिलीज़ होने वाली सभी फिल्में देखें
3. **सभी फिल्में देखें** - डेटाबेस में सभी फिल्में देखें
4. **देखी गई फिल्म जोड़ें** - किसी उपयोगकर्ता के लिए फिल्म को देखे गए के रूप में चिह्नित करें
5. **देखी गई फिल्में देखें** - किसी उपयोगकर्ता द्वारा देखी गई सभी फिल्में देखें
6. **ऐप में उपयोगकर्ता जोड़ें** - एक नया उपयोगकर्ता बनाएं
7. **फिल्म खोजें** - शीर्षक के आधार पर फिल्म खोजें
8. **बाहर निकलें** - एप्लिकेशन बंद करें

## डेटाबेस संरचना

एप्लिकेशन SQLite डेटाबेस (`data.db`) का उपयोग करता है जिसमें तीन टेबल हैं:

### Movies टेबल
- `id` - प्राथमिक कुंजी
- `title` - फिल्म का शीर्षक
- `release_timestamp` - रिलीज़ तारीख (Unix timestamp)

### Users टेबल
- `username` - उपयोगकर्ता नाम (प्राथमिक कुंजी)

### Watched टेबल
- `user_username` - उपयोगकर्ता नाम (foreign key)
- `movie_id` - फिल्म ID (foreign key)

## फ़ाइल संरचना

```
.
├── app.py          # मुख्य एप्लिकेशन फ़ाइल
├── database.py     # डेटाबेस संचालन और क्वेरी
├── data.db         # SQLite डेटाबेस फ़ाइल
├── index.html      # रंग बदलने वाला बटन डेमो
└── README.md       # यह फ़ाइल
```

## उदाहरण

### फिल्म जोड़ना
```

Release date (dd-mm-YYYY): 16-07-2010
```

```

```

यह "Inception" जैसे शीर्षक वाली सभी फिल्मों को वापस करेगा।
