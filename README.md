# A-movie-Watch-List-app-using-python-and-sql

## Blue to Red Button Feature

This repository includes a simple interactive button demonstration in `index.html`.

### Features
- A blue button is displayed on the page
- When clicked, the button changes from blue to red
- The color change is permanent (stays red after clicking)

### How to Use
1. Open `index.html` in any web browser
2. Click the blue button
3. The button will turn red

### Technical Implementation
- Pure HTML, CSS, and JavaScript (no dependencies)
- Uses CSS class toggling for color change
- Smooth transition effect for visual appeal
