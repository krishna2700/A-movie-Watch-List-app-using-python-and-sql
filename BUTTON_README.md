# Color Changing Button

## Overview
This project contains a simple interactive button that changes color when clicked.

## Features
- **Initial State**: The button starts with a blue background
- **Interactive**: When clicked, the button changes to red
- **Responsive Design**: Centered layout that works on different screen sizes
- **Smooth Transition**: Color change includes a smooth CSS transition effect

## Files
- `index.html`: Main HTML file containing the button implementation

## How It Works
1. The button is initially styled with a blue background using CSS
2. A JavaScript event listener is attached to the button
3. When the button is clicked, the JavaScript changes the background color to red

## Usage
Simply open `index.html` in any modern web browser and click the button to see it change from blue to red.

## Technical Details
- **HTML**: Semantic HTML5 structure
- **CSS**: Inline styles with flexbox for centering
- **JavaScript**: Vanilla JavaScript using `addEventListener` for event handling

## Browser Compatibility
Works in all modern browsers that support:
- HTML5
- CSS3 (flexbox, transitions)
- ES5+ JavaScript
