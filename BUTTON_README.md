# Blue to Red Button

This is a simple interactive button implementation that changes color when clicked.

## Overview

The button starts with a blue background and turns red when clicked by the user.

## Features

- Initial state: Blue background with white text
- On click: Changes to red background
- Smooth color transition animation
- Responsive centered layout
- Hover effect for better user interaction

## Technical Details

### File Location
`button.html`

### Implementation
- Pure HTML, CSS, and JavaScript (no frameworks required)
- Uses CSS classes and inline styles for color change
- Event listener attached to button click event

### Styling
- Button padding: 15px 30px
- Font size: 18px
- Border radius: 5px for rounded corners
- Transition effect: 0.3s ease for smooth color change

## Usage

Simply open `button.html` in any modern web browser. Click the button to see it change from blue to red.

## Browser Compatibility

Works in all modern browsers that support:
- ES6 JavaScript
- CSS3 transitions
- DOM event listeners

## Code Structure

1. **HTML**: Single button element with id "colorButton"
2. **CSS**: Styling for button appearance and red state class
3. **JavaScript**: Click event listener that applies red background color
