# मूवी वॉचलिस्ट ऐप

यह एक Python और SQL पर आधारित मूवी वॉचलिस्ट ऐप है जो आपको अपनी पसंदीदा मूवीज़ ट्रैक करने में मदद करता है।

## विशेषताएं

- नई मूवी जोड़ें
- आगामी मूवीज़ देखें
- सभी मूवीज़ देखें
- देखी गई मूवी जोड़ें
- देखी गई मूवीज़ देखें
- ऐप में यूज़र जोड़ें
- मूवी खोजें

## उपयोग

ऐप चलाने के लिए निम्न कमांड का उपयोग करें:

```bash
python app.py
```

## मेनू विकल्प

1) नई मूवी जोड़ें
2) आगामी मूवीज़ देखें
3) सभी मूवीज़ देखें
4) देखी गई मूवी जोड़ें
5) देखी गई मूवीज़ देखें
6) यूज़र जोड़ें
7) मूवी खोजें
8) बाहर निकलें

## आवश्यकताएं

- Python 3
- SQLite डेटाबेस
