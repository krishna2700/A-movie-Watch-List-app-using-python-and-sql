# Application de liste de films à regarder en Python et SQL

Ce projet est une application simple qui permet de gérer une liste de films à regarder. Il s'appuie sur Python pour la logique et une base de données SQL pour le stockage.

## Fonctionnalités

- Ajouter des films à votre liste
- Consulter votre liste de films
- Mettre à jour ou supprimer des entrées

## Technologies

- Python
- SQL

## Démarrage rapide

1. Assurez-vous d'avoir Python installé.
2. Lancez l'application avec `python app.py`.
