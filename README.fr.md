# Application de liste de films à regarder en Python et SQL

Ce projet est une application simple de liste de films à regarder, construite en Python avec une base de données SQL. Il permet de gérer une collection de films que vous souhaitez voir.

## Fonctionnalités

- Ajouter des films à la liste
- Consulter la liste des films
- Mettre à jour les informations d’un film
- Supprimer des films

## Prérequis

- Python 3

## Utilisation

1. Assurez-vous d’avoir Python 3 installé.
2. Lancez l’application avec :

```bash
python app.py
```

## Structure du projet

- `app.py` : point d’entrée de l’application
- `database.py` : gestion de la base de données
- `data.db` : base de données SQLite
