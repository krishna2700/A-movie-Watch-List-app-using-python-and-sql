# मूवी वॉचलिस्ट ऐप - Python और SQL का उपयोग करके

यह एक साधारण कमांड-लाइन आधारित मूवी वॉचलिस्ट एप्लिकेशन है जो Python और SQLite का उपयोग करके बनाया गया है। यह ऐप उपयोगकर्ताओं को फिल्मों को ट्रैक करने, उन्हें देखे गए के रूप में चिह्नित करने और अपनी व्यक्तिगत वॉचलिस्ट प्रबंधित करने की अनुमति देता है।

## विशेषताएं

- **नई फिल्म जोड़ें**: अपनी वॉचलिस्ट में रिलीज़ की तारीख के साथ फिल्में जोड़ें
- **आगामी फिल्में देखें**: उन फिल्मों को फ़िल्टर करें जो भविष्य में रिलीज़ होने वाली हैं
- **सभी फिल्में देखें**: डेटाबेस में सभी फिल्मों की सूची देखें
- **देखी गई फिल्म जोड़ें**: फिल्मों को देखे गए के रूप में चिह्नित करें
- **देखी गई फिल्में देखें**: किसी उपयोगकर्ता द्वारा देखी गई सभी फिल्मों की सूची देखें
- **उपयोगकर्ता जोड़ें**: ऐप में नए उपयोगकर्ता पंजीकृत करें
- **फिल्म खोजें**: शीर्षक के आधार पर फिल्मों को खोजें

## आवश्यकताएं

- Python 3.8 या उच्चतर
- SQLite3 (Python के साथ बिल्ट-इन आता है)

## उपयोग

ऐप को चलाने के लिए:

```bash
python app.py
```

### मेनू विकल्प

ऐप शुरू होने पर, आपको निम्नलिखित विकल्पों के साथ एक मेनू दिखाई देगा:

1. **नई फिल्म जोड़ें**: फिल्म का शीर्षक और रिलीज़ की तारीख (dd-mm-YYYY फॉर्मेट में) दर्ज करें
2. **आगामी फिल्में देखें**: केवल भविष्य की रिलीज़ वाली फिल्में प्रदर्शित करता है
3. **सभी फिल्में देखें**: डेटाबेस में सभी फिल्मों को प्रदर्शित करता है
4. **देखी गई फिल्म जोड़ें**: उपयोगकर्ता नाम और मूवी ID दर्ज करें
5. **देखी गई फिल्में देखें**: किसी विशिष्ट उपयोगकर्ता के लिए देखी गई फिल्में दिखाता है
6. **ऐप में उपयोगकर्ता जोड़ें**: एक नया उपयोगकर्ता पंजीकृत करें
7. **फिल्म खोजें**: फिल्म के शीर्षक के आंशिक नाम से खोजें
8. **बाहर निकलें**: एप्लिकेशन बंद करें

## प्रोजेक्ट संरचना

```
.
├── app.py          # मुख्य एप्लिकेशन फ़ाइल (यूजर इंटरफेस और मेनू लॉजिक)
├── database.py     # डेटाबेस ऑपरेशन और SQL क्वेरी
├── data.db         # SQLite डेटाबेस फ़ाइल (स्वचालित रूप से बनाई गई)
└── README.md       # प्रोजेक्ट दस्तावेज़ीकरण
```

## डेटाबेस स्कीमा

### Movies टेबल
- `id`: INTEGER PRIMARY KEY
- `title`: TEXT
- `release_timestamp`: REAL

### Users टेबल
- `username`: TEXT PRIMARY KEY

### Watched टेबल
- `user_username`: TEXT (Foreign Key)
- `movie_id`: INTEGER (Foreign Key)

## उदाहरण वर्कफ़्लो

1. ऐप शुरू करें: `python app.py`
2. एक उपयोगकर्ता जोड़ें (विकल्प 6)
3. फिल्में जोड़ें (विकल्प 1)
4. आगामी फिल्में देखें (विकल्प 2)
5. फिल्म को देखे गए के रूप में चिह्नित करें (विकल्प 4)
6. अपनी देखी गई फिल्में देखें (विकल्प 5)

## तकनीकी विवरण

- **डेटाबेस**: SQLite3 का उपयोग स्थानीय डेटा भंडारण के लिए
- **तारीख प्रबंधन**: Python की datetime लाइब्रेरी का उपयोग
- **इंडेक्सिंग**: बेहतर प्रदर्शन के लिए release_timestamp पर इंडेक्स
- **Foreign Keys**: डेटा अखंडता बनाए रखने के लिए
