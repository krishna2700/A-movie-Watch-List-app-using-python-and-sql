# मूवी वॉचलिस्ट ऐप

Python और SQL का उपयोग करके बनाई गई एक मूवी वॉचलिस्ट एप्लीकेशन

## परियोजना के बारे में

यह एक कमांड-लाइन आधारित मूवी वॉचलिस्ट एप्लीकेशन है जो उपयोगकर्ताओं को फिल्मों को ट्रैक करने, उपयोगकर्ताओं को प्रबंधित करने और देखी गई फिल्मों को रिकॉर्ड करने की अनुमति देती है। यह Python में लिखी गई है और डेटा स्टोरेज के लिए SQLite डेटाबेस का उपयोग करती है।

## विशेषताएं

- ✅ नई फिल्में जोड़ें (शीर्षक और रिलीज़ की तारीख के साथ)
- ✅ आगामी फिल्में देखें (वर्तमान तिथि से बाद की)
- ✅ सभी फिल्में देखें
- ✅ फिल्मों को "देखी गई" के रूप में चिह्नित करें
- ✅ उपयोगकर्ता द्वारा देखी गई फिल्मों की सूची देखें
- ✅ ऐप में नए उपयोगकर्ता जोड़ें
- ✅ फिल्मों को शीर्षक से खोजें

## तकनीकी स्टैक

- **भाषा**: Python 3
- **डेटाबेस**: SQLite3
- **मुख्य लाइब्रेरी**:
  - `datetime` - तारीख और समय प्रबंधन के लिए
  - `sqlite3` - डेटाबेस संचालन के लिए

## फाइल संरचना


## डेटाबेस स्कीमा

### तालिकाएं

1. **movies**
   - `id` (INTEGER PRIMARY KEY) - फिल्म की अद्वितीय पहचान
   - `title` (TEXT) - फिल्म का शीर्षक
   - `release_timestamp` (REAL) - रिलीज़ की तारीख (Unix timestamp)

2. **users**
   - `username` (TEXT PRIMARY KEY) - अद्वितीय उपयोगकर्ता नाम

3. **watched**
   - `user_username` (TEXT) - उपयोगकर्ता नाम (foreign key)
   - `movie_id` (INTEGER) - फिल्म ID (foreign key)

### इंडेक्स

- `movies_release_idx` - रिलीज़ तिथि पर इंडेक्स (तेज़ क्वेरी के लिए)

## उपयोग

एप्लीकेशन चलाने पर, आपको एक मेनू दिखाई देगा:

```
Please select one of the following options:
1) Add new movie.
2) View upcoming movies.
3) View all movies
4) Add watched movie
5) View watched movies.
6) Add user to the app.
7) Search for a movie.
8) Exit.
```

### उदाहरण उपयोग

#### 1. नई फिल्म जोड़ना
- विकल्प `1` चुनें
- फिल्म का शीर्षक दर्ज करें
- रिलीज़ की तारीख दर्ज करें (dd-mm-YYYY फॉर्मेट में)
- यदि खाली छोड़ा जाए तो आज की तारीख डिफ़ॉल्ट रूप से उपयोग की जाएगी

#### 2. आगामी फिल्में देखना
- विकल्प `2` चुनें
- वर्तमान तिथि के बाद रिलीज़ होने वाली सभी फिल्में प्रदर्शित होंगी

#### 3. फिल्म को देखी गई के रूप में चिह्नित करना
- विकल्प `4` चुनें
- उपयोगकर्ता नाम दर्ज करें
- फिल्म ID दर्ज करें (विकल्प 3 से प्राप्त)

#### 4. उपयोगकर्ता जोड़ना
- विकल्प `6` चुनें
- उपयोगकर्ता नाम दर्ज करें

#### 5. फिल्म खोजना
- विकल्प `7` चुनें
- आंशिक या पूर्ण फिल्म शीर्षक दर्ज करें
- मेल खाने वाली सभी फिल्में प्रदर्शित होंगी

## मुख्य कार्यक्षमता

### app.py

- **prompt_add_movie()**: नई फिल्म जोड़ने के लिए उपयोगकर्ता इनपुट
- **print_movie_list()**: फिल्मों की सूची को फॉर्मेट और प्रिंट करता है
- **prompt_watch_movie()**: फिल्म को देखी गई के रूप में चिह्नित करना
- **prompt_get_watched_movies()**: उपयोगकर्ता की देखी गई फिल्में प्राप्त करना
- **prompt_add_user()**: नया उपयोगकर्ता जोड़ना
- **prompt_search_movies()**: फिल्मों को खोजना

### database.py

- **create_tables()**: डेटाबेस तालिकाएं और इंडेक्स बनाता है
- **add_movie()**: डेटाबेस में नई फिल्म जोड़ता है
- **get_movies()**: सभी या आगामी फिल्में प्राप्त करता है
- **add_user()**: नया उपयोगकर्ता जोड़ता है
- **watch_movie()**: फिल्म और उपयोगकर्ता को watched तालिका में जोड़ता है
- **get_watched_movies()**: किसी उपयोगकर्ता द्वारा देखी गई सभी फिल्में प्राप्त करता है
- **search_movies()**: शीर्षक के आधार पर फिल्में खोजता है

## तिथि प्रारूप

- **इनपुट प्रारूप**: dd-mm-YYYY (उदाहरण: 25-12-2024)
- **प्रदर्शन प्रारूप**: MMM dd YYYY (उदाहरण: Dec 25 2024)
- **आंतरिक भंडारण**: Unix timestamp (REAL)

## विशेषताएं

- ✅ **उपयोगकर्ता के अनुकूल इंटरफ़ेस**: सरल कमांड-लाइन मेनू
- ✅ **डेटा स्थिरता**: SQLite के साथ स्थायी भंडारण

- ✅ **प्रदर्शन अनुकूलन**: रिलीज़ तिथि पर इंडेक्स
- ✅ **तारीख प्रबंधन**: स्वचालित तारीख पार्सिंग और फॉर्मेटिंग
